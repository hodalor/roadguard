# RoadGuard Mobile

Flutter-ready starter app for motorists using the RoadGuard Ghana platform.

## Planned Features

- SOS emergency activation
- Nearby provider discovery
- Hazard reporting
- Offline emergency information
- Emergency contact management

## Firebase

- Copy `.env.example` to `.env`
- Add your Firebase project values in `.env`
- Add `google-services.json` and `GoogleService-Info.plist` after generating native platform folders
- This starter includes Firebase Auth and Firebase Cloud Messaging scaffolding
